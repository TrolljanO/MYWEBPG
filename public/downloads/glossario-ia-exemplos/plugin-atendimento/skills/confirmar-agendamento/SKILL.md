# Confirmar agendamento

1. Consulte os horários de amanhã pela ferramenta da agenda (servidor MCP "agenda" deste plugin).
2. Pra cada horário, monte um rascunho curto: nome, data, hora e endereço.
3. Mostre os rascunhos pro usuário e espere aprovação. Não envie nada sozinho.
